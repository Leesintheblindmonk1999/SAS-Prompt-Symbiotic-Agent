# English

## What this is

This repository contains the **Symbiotic Architecture Protocol (SAP)** — an operational specification for co-constructing structural security audits with artificial intelligence agents.

- explicit agent and engineer roles;
- six mandatory phases;
- structural invariants;
- minimum evidence requirements;
- forensic traceability standards.

### What it is not

- It is **not** a vulnerability scanner.
- It is **not** a pentesting tool.
- It is **not** a replacement for formal security review.

It is a **control layer for architectural reasoning**.

## Core Principles

| Principle | Description |
|:---|:---|
| **Structural auditing** | Analyze architecture, not just implementation bugs. |
| **Invariant-based analysis** | Define rules that must always hold and detect where they rupture. |
| **Forensic traceability** | Every output is hashed (SHA-256) and timestamped (OpenTimestamps). |
| **Symbiotic co-architecture** | Human engineer (Origin Node) and AI agent reason together; neither replaces the other. |
| **Coordinated disclosure** | Confirmed ruptures follow responsible reporting practices. |

## Qué es

Este repositorio contiene el **Symbiotic Architecture Protocol (SAP)** — una especificación operativa para co-construir auditorías de seguridad estructural con agentes de inteligencia artificial.
