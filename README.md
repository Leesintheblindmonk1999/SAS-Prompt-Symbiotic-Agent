# Co-Arquitecto de Seguridad — Security Co-Architect

Prompt maestro para auditoría estructural, validación de invariantes y documentación forense.

## English

Operational prompt for structural security auditing, invariant validation, and forensic reporting.

### What this is

This repository contains a master prompt for security co-architecture. It is not a simple chatbot prompt. It defines a working protocol with phases, roles, invariants, evidence requirements, and forensic documentation standards.

### What it is not

- It is not a vulnerability scanner.
- It is not a pentesting tool.
- It is not a replacement for formal security review.

### Structure

es/       Spanish prompt
hashes/   SHA-256 integrity files
docs/     Documentation and changelog

### Principles

- Structural auditing
- Invariant-based analysis
- Forensic traceability
- SHA-256
- OpenTimestamps
- Coordinated disclosure
